# EffectiveComm
A free static prototype for a school project.

## Run locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a GitHub repository named `effectivecomm`.
2. Upload `index.html`.
3. Open Settings -> Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public URL.

This prototype uses browser localStorage for demo progress and contains no real employee data.
